# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |

## Reporting a vulnerability

Please report security issues privately by email to **info@ligatrix.com**, not through public issues.

Include:

- the version (`secret-scan --version`) and Node.js version;
- what is affected: a credential format that is missed, a way to make the scanner print an unmasked value, a crash or
  hang on crafted input, or anything else;
- steps or a minimal file to reproduce it. Describe credential shapes rather than sending real values.

We acknowledge every report within 2 business days, keep you informed while we work on a fix, and credit you in the
release notes if you wish.
